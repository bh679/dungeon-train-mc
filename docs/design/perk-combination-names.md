# Perk combination names (draft)

Your name comes from your **top 2 classes by points, in order**: the class with the most points first. 1 + 10 + 90 = **101 names**.

**Ties:** when classes tie on points, the class that got its first point earliest ranks higher.

- Nothing active: **Passenger**
- One class: the class's own name
