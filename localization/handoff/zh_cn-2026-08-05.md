## How to send it back

Fill in `verdict` (and `new_translation` where you rewrite a line) and return the CSVs —
that is the whole ask. `ok` = fine as-is (credited as reviewed by you, original author
kept), `fixed` = your wording in `new_translation` (you become author *and* reviewer),
`skip` = leave for later, blank = untouched. A partly-filled file is fine to return at
any time.

Books are reviewed whole: read `english_file` and `translation_file`, set `verdict`, and
edit the translation file directly if you rewrite it. For the four new books, just add
the `translation_file` shown.

Please don't hand-edit anything under `localization/provenance/` — the in-game AI badge
and its blue ring are generated from those files and CI fails if they drift. I'll run:

```bash
python3 scripts/localization/apply-review-csv.py --reviewer 老本願 \
    localization/review/zh_cn/dungeontrain-ui.csv
```

Regenerate this queue any time with
`python3 scripts/localization/build-review-package.py`.
